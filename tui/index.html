Rust core · in-memory watch cache · in-process AI assistant · zero Electron

The terminal control room
for Kubernetes.

Built on ratatui and kube-rs, srelens-tui delivers the full operational power of srelens inside a single, fast native binary. Featuring an in-memory Informer cache that redraws views you have already opened without a new request, live streaming watches, BGP network peering dashboards, Helm 3 values diffs, auto-wrapped logs, and an embedded AI assistant with per-reply token estimates.

#features · Core Capabilities

Engineered for high-stakes SRE operations.

Everything you need during on-call incidents: live peering states, instant AI triage playbooks, smart auto-wrapped logs, Helm values diffs, and hierarchy trees.

In-Process AI Diagnostics

Embedded SRE AI Assistant (:ai or Tab)#

An intelligent troubleshooting companion embedded directly in your terminal. No external browser context-switching required.

  • Incident Playbooks: Run /crashloop, /oom, /rollout, or /endpoints to diagnose failing workloads with grounded root cause analysis.
  • Tool Badges & Execution: Transparently runs diagnostic tools (manifest and event reads, log tailing, metrics). Tools that change the cluster are blocked in the assistant; MCP clients can use them by launching srelens-tui mcp --allow-destructive.
  • Multi-Provider & Token Estimates: Each reply shows an estimated token count and the reply time. Connect Anthropic Claude, OpenAI, Google Gemini, or any OpenAI-compatible endpoint such as local Ollama.
  • High-Density Caveman Mode: Use /caveman for terse, ultra-compact operational output designed for high-stress pager duty.

Model Context Protocol

Headless MCP Server (srelens-tui mcp)#

Expose pure, native Kubernetes capabilities directly to your AI coding agents. Run srelens-tui mcp to let Cursor, Claude Desktop, Claude Code, and Gemini inspect, diagnose, and remediate clusters in real time.

  • Direct Agent Integration: Plug into Cursor (.cursor/mcp.json), Claude Desktop, Claude Code, or Gemini CLI via stdio transport.
  • 100+ Native Tools: Agents invoke high-performance cluster primitives — tailing multi-pod logs, inspecting manifests, querying metrics, and analyzing topology.
  • Granular Safety Flags: Gate sensitive reads with --allow-sensitive-reads and mutating actions (scale, restart, apply, delete) with --allow-destructive.
  • Zero Cloud Relay: Operates 100% locally over stdio against your local kubeconfig. No cluster credentials, tokens, or telemetry leave your machine.

GitOps & Continuous Delivery

ArgoCD Applications & Sync Dashboard (:argo)#

Monitor and trigger GitOps deployments across multiple ArgoCD clusters and namespaces straight from the terminal.

  • Application Health & Sync: Instant tabular overview of sync statuses (Synced, OutOfSync) and resource health (Healthy, Degraded, Progressing).
  • Revision & Repo Tracking: View target Git repositories, branches, commit SHAs, and destination server endpoints.
  • Direct Drilldown: Press Enter to inspect application resources, conditions, and sync details.

Cluster Telemetry & Capacity

Real-Time Cluster Overview & Telemetry (:overview)#

Instant bird's-eye view of cluster-wide resource allocation, capacity pressure, and node health metrics in a single high-density pane.

  • Live Resource Gauges: Real-time visual progress bars for cluster-wide CPU and memory utilization, plus GPU when present.
  • Node Fleet Health: See how many nodes are Ready at a glance.
  • Cached Refresh: The in-memory Informer cache keeps opened views current from live watches; pod and node metrics refresh about every 4 seconds.

Workload Operations

High-Density Pod & Resource Operations (:pods)#

Keyboard-optimized table views with in-memory sorting, persistent regex filtering, and deep operational shortcuts.

  • Instant Shells (s): Drops straight into a container shell, trying /bin/sh, then bash, through your local kubectl.
  • Privileged Node Shells (s on Nodes): Launch a root debug shell on a node with host namespace access via kubectl debug.
  • Background Port Forwarding (Shift + F): Manage port forwards with live byte counters and automatic reconnection.

Release Management

Deep Helm 3 Inspector & Values Diff (:helm)#

Inspect Helm releases across all namespaces directly from your terminal. Releases, history, values and manifests are read from the cluster without the helm CLI; rollback uses your local helm.

  • Three Diff Modes: Built-in diff engine compares User-Supplied Values against Computed All-Values, chart defaults, or the previous release revision (press m to cycle).
  • Revision Changelog: Complete historical release audit trail with deployed timestamps, chart versions, and status.
  • One-Touch Rollback: Select any prior revision in the history list and press r to trigger a guarded, confirmation-backed rollback.
  • Rendered Manifests: View syntax-highlighted rendered Kubernetes YAML manifests generated by the chart templates.

AI & Accelerator Infrastructure

GPU Fleet & VRAM Allocation Telemetry (:gpuinfo)#

First-class hardware visibility for AI/ML inference and training clusters without manual NVIDIA SMI scripting.

  • Hardware Discovery: Automatically identifies physical GPU accelerator models (NVIDIA H100, A100, L4, T4, Tesla) and driver versions.
  • VRAM Capacity Gauges: Live visual bars for allocated vs. allocatable GPU memory per node across the cluster.
  • Workload Attribution: Instantly map running training jobs, inference pods, and DCGM exporters to physical GPUs.

Networking & Control Plane

BGP Peering & Topology Dashboard (:bgp)#

First-class visibility into cloud-native routing. Automatically discovers and inspects Cilium BGP Control Plane, MetalLB, and Calico BGP peering topologies.

  • Peering Sessions: BGP neighbors with remote ASN, session state (Established when the CNI reports it, otherwise Configured), and uptime for Cilium.
  • Prefix Announcements: Track advertised Service VIPs and Pod CIDRs, plus the configured hold and keep-alive timers for each peer.
  • Multi-Router Topology: Inspect BGP node peer configurations, router IDs, and autonomous system boundaries.

Telemetry & Logging

Engineered Multi-Pod Log Streamer (l)#

Designed specifically for modern JSON and structured logging formats where single log events span hundreds of characters.

  • Hanging Indent Wrap: Enabled by default, long log lines wrap cleanly beneath the line number gutter (│ continuation) so line numbers remain readable and aligned.
  • Log Severity Highlighting: Colors error and fatal lines red, warnings yellow, and debug lines dim across all log streams.
  • Crashed Container Logs: Press p to instantly toggle previous container instance logs to find fatal stack traces before container termination.
  • Horizontal Panning & Search: Toggle wrapping off with w for horizontal scrolling (h/l or arrows), and search log lines in real time with / (n/N jump between matches).

Topology & Relationships

Visual Resource Hierarchy Trees (t)#

Instantly resolve the full owner-reference and dependency tree for any Kubernetes primitive without manually correlating labels or selector strings.

  • Full Stack Topology: Follows relationships from Ingress ➔ Service ➔ Deployment ➔ ReplicaSet ➔ Pods, plus mounted ConfigMaps, Secrets, PVCs and the hosting Node.
  • Live Health Dots: Visual status indicators beside every node in the tree show replica readiness, crash counts, and degraded states.
  • Direct Drilldown: Press Enter on any sub-resource in the tree to jump directly to its detail view or open live logs.
