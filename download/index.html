● Package Manager

Install via Homebrew.

On macOS and Linux, install the prebuilt srelens-tui formula via the official Homebrew tap. 

# install via Homebrew (macOS & Linux)
$ brew install srelens/tap/srelens-tui

# launch srelens-tui
$ srelens-tui

● First run

From installer to cluster in a minute.

Open the app, pick a context from your local kubeconfig, and open a workspace. This is what greets a new install — installers may trigger your operating system’s first-launch prompts.

● Hacking on it?

Or run it from source.

Prefer to build it yourself — or want to contribute? The app builds and runs with the standard Rust and pnpm toolchains.

Requires Rust (stable), Node.js 22+, pnpm 9+, and the Tauri v2 prerequisites for your platform. 

# clone and run the desktop app
$ git clone https://github.com/srelens/srelens
$ cd srelens
$ pnpm install
$ pnpm dev
