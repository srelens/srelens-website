Kubernetes Dashboard is archived. What should replace it?

The official Kubernetes Dashboard repository was archived on January 21, 2026 and recommends Headlamp. That is the clearest migration if you still need a shared in-cluster web UI. Choose srelens when you would rather remove the dashboard from the cluster and give each engineer a local desktop workspace.

archived Jan 2026migration guidereviewed July 2026

Choose srelens when

  • You do not need a shared browser URL.
  • You want no UI component, gateway, or ingress running in the cluster.
  • Local logs, terminals, YAML, port forwards, and MCP belong in one desktop workspace.

Choose Headlamp when

  • You need a maintained in-cluster web UI.
  • Central browser access and Kubernetes RBAC are requirements.
  • You want the replacement explicitly recommended by the archived Dashboard project.

Is Kubernetes Dashboard still safe to keep using?

An archived project no longer receives normal maintenance. Assess your deployment and security requirements promptly; this page does not make a security claim about a particular installed version.

Does srelens require a Helm chart or ingress?

No. Install it on the user’s macOS, Windows, or Linux machine and connect with the same local kubeconfig used by kubectl.

Is srelens the official successor?

No. The archived Kubernetes Dashboard repository explicitly points to Headlamp. srelens is an independent alternative for teams choosing a local desktop model instead of another in-cluster web UI.
